# Anson Chan — Portfolio

A focused software engineering portfolio built with Next.js, React, and TypeScript.

The landing page includes:

- Education and experience
- Project demos and source links
- A light/dark theme
- A local music player
- Contact and résumé links

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production check

```bash
npm run build
npm start
```
